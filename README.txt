# Study Mate AI — Starter Project

## Run the project
1. Extract this ZIP file.
2. Open the `study_mate_ai` folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click inside the file and choose **Open with Live Server** (if you have the Live Server extension).
   - If Live Server is not installed, you can double-click `index.html` to open it in your browser.

## Files
- `index.html` — website structure
- `style.css` — colours, layout and responsive design
- `script.js` — buttons, assignment manager, planner, to-do list, demo assistant and browser storage

## Important project note
Assignments, study sessions and to-do items are saved in the browser using LocalStorage. The AI Study Assistant currently gives sample/demo responses; it is not connected to a real AI model or API. Do not describe it as a live AI chatbot in your report until a secure backend and AI API are added.

## Suggested first test
1. Add an assignment.
2. Mark it complete.
3. Add a study session.
4. Add and tick a to-do item.
5. Refresh the browser and confirm that your data remains.
